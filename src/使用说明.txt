NVMe 固态修复 / 重装系统工具 v6
https://github.com/derek114514/nvme-ssd-rescue
==================================================

 适用：装 Windows 时“选择安装位置”一个盘都没有、看到盘却装不上、
       BIOS 认不到固态、开机只能进 BIOS 等情况。英特尔 / AMD 平台都能用。

 这个 U 盘有两种用法：
   A. 插着它开机 → 自动进修复系统，弹出中文检测窗口，告诉你问题出在哪（第一节）
   B. 和 Windows 安装 U 盘一起插，在安装界面按 Shift+F10，输入 D:\fix（第三节）
 两种都不行时看第四节。


一、先检测（推荐第一步就做，不改动任何东西）
--------------------------------------------------
 1. 进 BIOS 把 Secure Boot 关掉（修复系统没有微软签名，不关进不去，修完可以再打开）。
    常见进 BIOS 按键：华硕 F2，联想 F2 或 F1，戴尔 F2，惠普 F10，微星 Del。
 2. 插上本 U 盘开机，按启动菜单键（华硕 Esc，联想 / 戴尔 F12，惠普 F9，微星 F11），
    选带“UEFI”字样的 U 盘。SystemRescue 菜单直接回车。
 3. 大约 1 分钟后进入桌面，自动弹出黑色检测窗口。
    没弹出来：双击桌面的“SSD Fix”；或者在终端输入
      bash /run/archiso/bootmnt/usb-ssd-fix/start_gui.sh
 4. 看检测结论，按提示输入菜单数字：
      · “固态是好的，原来的 Windows 还在，只是启动文件丢了” → 输入 8（第二节第 1 条）
      · “固态被 VMD 藏起来了” → 看第四节第 1、2 条
      · 固态有问题 / 不要原来的数据了 → 输入 9 深度修复（第二节第 2 条）
    检测报告保存在 U 盘 usb-ssd-fix 文件夹里（report_linux_日期.txt），可以发给别人帮你看。


二、修复系统里的两个主要功能
--------------------------------------------------
 1. 修复启动（菜单 8，不删数据，不需要 Windows 安装盘）
    适用：开机直接进 BIOS，但固态里原来的 Windows 还在。
    它会：把 Windows 分区里的启动文件拷回 EFI 分区 → 生成启动配置
          → 在主板里登记“Windows Boot Manager”并排第一。
    改动前会把原来的 EFI 分区备份到 U 盘（esp_backup_日期.tgz）。
    完成后关机拔 U 盘开机：
      · 进了 Windows → 修好了，可以把 Secure Boot 打开。
      · 蓝屏 INACCESSIBLE_BOOT_DEVICE → 原系统是开着 VMD 装的，回 BIOS 把 VMD 打开。

 2. 深度修复固态（菜单 9，会清空固态全部数据）
    依次做：复位固态主控 → 存储空间（命名空间）丢了就找回 / 重建
            → 固态自带的安全擦除 → 全盘多处写入读回比对 → 固态自检 → 写空白分区表。
    一般 3~10 分钟。结果是“修好了”就去装系统；“没修好”说明是硬件或固件问题，找售后。


三、在 Windows 安装界面里用（D:\fix）
--------------------------------------------------
 1. 用 Windows 安装 U 盘启动，走到“你想将 Windows 安装在哪里？”。
 2. 把本 U 盘也插上，按 Shift+F10（笔记本可能要 Shift+Fn+F10），
    在黑色窗口里输入  D:\fix  回车（提示找不到就把 D 换成 E、F、G……）。
 3. 输入 1 回车（一键修复固态并准备安装），核对型号和容量，输入大写 YES。
    它会：找到固态 → 解除只读 → 清空 → 转 GPT → 建好分区 → 写入读回校验。
    看不到固态时会先自动诊断原因（VMD、驱动、硬件），并告诉你下一步。
 4. 按任意键关掉窗口，回到安装界面点“刷新”，选名字是 Windows 的分区，点“下一步”。
 其它菜单：2 只诊断  3 加载 VMD 驱动  4 修复启动  5 磁盘详情  6 解除只读
           7 手动选盘清空  8 保存安装日志
 安全措施：U 盘、移动硬盘、虚拟盘一律不会被清空；清空前必须输入大写 YES。


四、开了 / 关了 VMD 还是不行？
--------------------------------------------------
 VMD（Intel Volume Management Device，BIOS 里也叫 RST / RAID / Intel VMD）
 会把 NVMe 固态藏在一个英特尔控制器后面。很多 Windows 安装盘不带它的驱动，
 所以“选位置”时一个盘都没有。处理办法：
   · 全新安装：BIOS 里把 VMD 改成 Disabled（或者把 RAID/RST 改成 AHCI）。
   · 要保留原系统：别关 VMD，在安装界面“加载驱动程序”，选 Intel RST 的 VMD 驱动
     （iaStorVD.inf）。驱动放进 usb-ssd-fix\drivers 后 D:\fix 选 3 也能自动加载。

 改了 VMD 还是不行，按现象对照：
 1. 加载了驱动还是没有盘
    → 驱动版本不对：要用和平台匹配的 Intel RST 驱动（11 代以后用 19.x / 20.x 这一代的
      VMD 驱动，压缩包名字带 f6 或 vmd），解压后选文件夹，别选 exe。
 2. 关了 VMD 能装，但装好后想打开 VMD，一开就蓝屏 INACCESSIBLE_BOOT_DEVICE
    → 系统是在关着 VMD 时装的，没有 VMD 驱动。要么一直关着，要么先装好 RST 驱动再打开。
    反过来也一样：开着 VMD 装的系统，关掉 VMD 也会蓝屏。
 3. 能看到盘，但提示“无法安装到这个磁盘 / 无法创建新的分区 / 找不到现有分区”
    → 分区表或分区残留（MBR/GPT 不对、只读、旧系统分区）。把这块盘上的分区全部删除，
      选“未分配的空间”再下一步；还不行就 D:\fix 选 1（清空 + 转 GPT + 建分区）。
      另外拔掉其它 U 盘 / 移动硬盘，只留安装 U 盘。
 4. 提示“这台电脑的硬件可能不支持启动到此磁盘”
    → U 盘是用传统模式（Legacy/CSM）启动的。启动菜单里选带“UEFI”字样的 U 盘，
      或者在 BIOS 里关掉 CSM。
 5. BIOS 里根本看不到固态（和 VMD 无关）
    → 拔掉电源适配器、长按电源键 40 秒放电；拆后盖把固态重新插紧或换一个 M.2 槽；
      然后用本 U 盘做检测（第一节）。检测说“控制器在、但没有可用的存储空间 / 容量 0”，
      多半是命名空间丢了或固件出错，菜单 9 深度修复能处理一部分；
      检测说“PCI 上看不到固态”就是硬件问题，找售后。
 6. 原来的系统还在，开机直接进 BIOS（例如用过改机器码 / 双系统工具之后）
    → 菜单 8 修复启动（第二节第 1 条），不删数据。

 关于“改机器码”：有的工具会改写固态固件里的序列号，出错时就会让固态“消失”。
 检测报告提示“序列号异常 / 型号异常”说明固件被动过；深度修复不会改回序列号，
 但只要读写和自检都正常，固态就能正常用。


五、说明
--------------------------------------------------
 · 修复系统是 SystemRescue 13.02（system-rescue.org），开机自动运行的设置在
   U 盘的 autorun 和 sysrescue.d 文件夹里，不要删。
 · 工具不会把任何数据发到网上。清空类操作不可恢复，重要数据请先备份。
